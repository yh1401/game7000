# 中了7000万 · 人生模拟器

> 一款「中奖之后的人生」文字模拟游戏。你中了 7000 万彩票，税后到手 5600 万。
> 接下来 10 年、120 个月，每个月你都要做一个选择——守住财富、心情与口碑，
> 还是像现实中约 70% 的大奖得主一样，在几年内滑向破产、入狱，甚至更凶险的结局。

在线试玩：<https://yh1401.github.io/game7000/>

---

## 特色

- **长线叙事**：120 个月、**87 个事件**、**14 种结局**（9 种黑暗结局 + 5 种十年结算）。
- **沉浸音效**：基于 Web Audio API **实时程序化合成**的背景音乐与音效，
  不需要任何外部音频文件，可离线运行、零体积负担。
- **语音朗读**：基于 Web Speech API 调用系统 TTS，自动朗读事件、选择结果与结局旁白，
  支持中英文，无需联网下载音色。
- **动态交互**：数字滚动、HUD 涨跌闪色、屏幕震动、飘字提示、金币雨、
  键盘快捷操作、事件流水账本。
- **强随机性**：加权随机事件池 + 条件触发 + 一次性事件，每一局都不一样。
- **零依赖**：纯 HTML + CSS + 原生 JavaScript，无框架、无构建步骤。

```
game7000/
├── index.html          # 入口：页面结构 + 资源引用
├── css/
│   └── style.css       # 全部样式：金色赌场主题、玻璃态、动画、响应式

│   ├── audio.js        # 音频引擎：BGM 与音效实时合成（Web Audio API）
│   ├── speech.js       # 语音引擎：用系统 TTS 朗读事件 / 结果 / 结局（Web Speech API）
│   ├── core.js         # 工具函数、数值格式化、游戏状态、特效与键盘
│   ├── events.js       # 事件库：87 个事件 / 14 种结局的素材数据
│   └── game.js         # 渲染、事件流程与结局判定
├── docs/
│   └── GAMEPLAY.md     # 玩法说明（规则 / 指标 / 事件分类 / 结局一览）
└── README.md
```

脚本按依赖顺序加载：`audio.js → speech.js → core.js → events.js → game.js`，全部为全局脚本，
**直接用浏览器打开 `index.html` 也能玩**（无需服务器）。

## 本地运行

方式一：直接双击 `index.html` 用浏览器打开。

方式二：起一个本地静态服务器（推荐，行为与线上一致）：

```bash
cd game7000
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

> 提示：浏览器要求音频必须由用户操作触发。点击首页「开奖」按钮后，
> 背景音乐与音效即会启动。右上角按钮或快捷键 `M`（音乐）/ `S`（音效）/ `R`（语音）可随时开关。

## 技术说明

### 音频引擎（`js/audio.js`）
- 使用 `AudioContext` 合成两条总线：`sfxBus`（音效）与 `bgmBus`（音乐）。
- 背景音乐为 `Am - F - C - G` 的柔和爵士进行，长音垫 + 琶音，用
  **lookahead 调度器**提前 0.6 秒排程，保证节奏稳定不卡顿。
- 音效覆盖：点击、翻页、进账、暴富、亏损、危险轰鸣、心跳、好/坏结局、金币等。
- 遵循浏览器自动播放策略：首次用户手势时调用 `AUDIO.unlock()` 解锁。

### 语音朗读（`js/speech.js`）
- 基于 **Web Speech API**（`speechSynthesis` + `SpeechSynthesisUtterance`）调用系统 TTS，
  **无需联网、无需下载音色**，直接使用操作系统自带的中文语音。
- 语音挑选策略：优先 `zh-CN`，其次 `zh-TW`/`zh-HK` 或任意 `zh` 语音；
  语音列表异步加载时通过 `onvoiceschanged` 重新选取。
- 朗读前会**清洗文本**：去掉 HTML 标签、引号、emoji，把换行 / `<br>` 转为停顿，
  让朗读更自然。
- 自动朗读三类内容：**事件**（标题 + 正文）、**选择结果**、**结局旁白**。
- 与 UI **解耦**：朗读开始 / 结束时在 `window` 上派发 `tts:start` / `tts:end`
  自定义事件，由主流程监听并驱动按钮的脉冲动画。
- 暴露全局 `TTS`：`speak / narrate / stop / toggle` 以及只读的 `supported / on`；
  若浏览器不支持则自动隐藏语音按钮。

### 游戏逻辑（`js/game.js` + `js/core.js` + `js/events.js`）
- 状态集中在全局对象 `S`；四维指标：总资产 / 月被动收入 / 心情 / 口碑。
- 事件对象格式：
  ```js
  { id, title, tag, w, once, cond, desc,
    options: [ { t, sub, fx(s){ /* 改变状态并返回结果叙述 */ } } ] }
  ```
  - `w`：随机权重（`0` 表示由条件专门触发）。
  - `once`：是否只出现一次；`cond(s)`：出现条件。
- 每月结算：被动收入 − 支出，基金按随机收益波动，心情向基准回归，
  随后按优先级判定是否触发特殊结局，否则抽取下一个事件。

## 部署到 GitHub Pages

1. 把本目录内容推送到仓库（如 `main` 分支）。
2. 仓库 **Settings → Pages → Source** 选择 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
3. 稍等片刻，访问 `https://<用户名>.github.io/<仓库名>/`。
