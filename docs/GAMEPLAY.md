# 玩法说明 · 中了7000万

本作是一款「中奖之后的人生」文字模拟游戏。你在开局中了 7000 万彩票，
扣除 20% 偶然所得税后到手 **5600 万**，随后人生按月推进，共 **10 年 / 120 个月**，
每个月发生一个事件，你做一个选择——直到迎来结局。

---

## 一、开局设定

| 项目 | 数值 |
| --- | --- |
| 中奖金额 | ¥70,000,000 |
| 偶然所得税 | 20% |
| 到手金额 | **5600 万**（记为「总资产」起点） |
| 游戏时长 | 120 个月（10 年） |
| 初始心情 / 口碑 | 72 / 70 |

---

## 二、四个核心指标

界面顶部实时显示。

1. **总资产** = 现金 + 存单/信托 + 基金 + 黄金 + 房产 + 生意。
2. **月被动收入** = 存单/信托利息 + 生意分红。**被动收入 > 月支出 = 财富自由**。
3. **心情（0–100）**：归零即触发「空心人」结局。
4. **口碑（0–100）**：影响部分事件走向与最终评价。

> 还有一个隐藏指标：**月支出**。基础生活水准分四档（低 / 一般 / 奢侈 / 顶奢），
> 再加上车、房、员工等固定开销。消费一旦升级，很难降回来——这是真实的陷阱。

---

## 三、每月流程

1. 展示本月事件与描述；
2. 你从 2–4 个选项中做出选择；
3. 系统结算该选择带来的资产 / 心情 / 口碑变化，并给出结果叙述；
4. 月度结算：`现金 += 被动收入 − 支出`，基金按随机收益波动（可能暴跌），
   心情向基准缓慢回归；
5. 判定是否触发特殊结局，否则抽取下一个月事件。

事件由**加权随机池**（`w`）+ **条件触发**（`cond`）+ **一次性标记**（`once`）共同决定，
所以每一局的经历都不相同。

## 四、操作方式

| 操作 | 说明 |
| --- | --- |
| 鼠标点击选项 | 选择当前事件的选项 |
| 数字键 `1`–`9` | 快速选择第 N 个选项 |
| `回车` / `空格` | 点击主按钮（开奖 / 继续 / 再中一次） |
| 右上角 🔊 | 音效开关（快捷键 `S`） |
| 右上角 🎵 | 背景音乐开关（快捷键 `M`） |

**音效说明**：背景音乐与音效均由 Web Audio API 实时合成，无外部音频文件。
因浏览器策略，需点击一次「开奖」后音频才会启动。

## 七、通关小技巧

1. **先建被动收入**：把一部分钱放进存单/信托，让利息覆盖基础开销，再谈其他。
2. **控制消费升级**：生活水准上去容易下来难，月支出是慢性杀手。
3. **管好心情**：心情归零即游戏结束，别把每件事都做成「赚钱机器」。
4. **分清骗局**：凡承诺「稳赚不赔、内幕消息、熟人项目」的，多半是坑。
5. **远离危险选项**：澳门、赌局、灰色交易是黑暗结局的高速入口。
6. **珍惜关系**：口碑与亲友关系在关键时刻能救命，也可能成为压垮你的最后一根稻草。

## 八、常见问题

**Q：为什么开局没有声音？**
A：浏览器要求音频由用户操作触发。点击首页「开奖」按钮后即会播放；若仍无声，
请检查右上角 🔊 / 🎵 是否被关闭。

**Q：可以直接双击 `index.html` 打开吗？**
A：可以。本项目为纯静态、全局脚本，无需服务器即可运行。

**Q：一局要玩多久？**
A：取决于你的速度。每个事件约 10–30 秒，完整一局约 120 个事件；
随时可能提前触发黑暗结局。也可以用数字键加速。

**Q：为什么每次玩的事件不一样？**
A：事件为加权随机抽取，并带有条件与一次性限制，因此每局体验都不同。
